# Strategy Workbench 개인정보처리방침

- 시행일: 2026년 7월 10일
- 운영자: Round1Studio
- 문의: [Strategy Workbench GitHub Issues](https://github.com/Darren83Kim/StrategyWorkbench/issues)

Strategy Workbench는 사용자가 시장 지표의 가중치를 조절하고 한국/미국 종목 샘플의 상대 순위와 지표 차이를 학습할 수 있도록 돕는 정보 제공 앱입니다. 이 앱은 증권 계좌 연결, 자산·포트폴리오 관리, 실제 주문, 매수 또는 매도 기능을 제공하지 않습니다.

## 1. 앱에서 처리하는 정보

앱은 사용자가 직접 입력하거나 앱 사용 중 생성되는 다음 정보를 기기 내에 저장할 수 있습니다.

- 사용자가 생성한 분석 기준 이름과 지표 가중치
- 관심 종목, 즐겨찾기, 현재 분석 기준 설정
- 종목별 짧은 관찰 메모와 확인 지표 태그
- 사용자가 직접 저장한 최근 분석 실험의 가중치와 당시 상위 샘플 순위
- 알림 설정, 화면 표시 설정, 캐시 데이터

현재 앱은 별도 회원가입이나 로그인을 요구하지 않으며, 사용자의 이름, 이메일 주소, 증권 계좌 정보, 자산 정보 또는 주문 정보를 수집하지 않습니다. 관찰 메모와 분석 실험 기록은 사용자의 기기 안에만 저장되며 앱 운영자 서버로 업로드되지 않습니다.

## 2. 외부 데이터 요청

종목 가격, 종목명, 재무 지표를 표시하기 위해 앱은 종목 코드 또는 티커를 외부 데이터 제공처에 요청할 수 있습니다. 이 요청은 종목 정보를 조회하기 위한 것이며, 사용자의 증권 계좌 정보나 개인 신원 정보를 함께 전송하지 않습니다.

표시되는 가격, 종목명, 재무 지표는 외부 데이터 제공처, 공개 시세 정보, 캐시 상태에 따라 지연되거나 실제 시장 정보와 다를 수 있습니다.

## 3. 광고

앱은 광고 제공을 위해 Google AdMob SDK를 사용할 수 있습니다. 광고 제공, 광고 성과 측정, 부정 사용 방지 등을 위해 Google 또는 광고 파트너가 기기 식별자, 광고 식별자, 앱 상호작용 정보, 대략적인 위치 정보 등을 처리할 수 있습니다.

광고 데이터 처리는 Google의 광고 및 개인정보 정책, 사용자의 기기 설정, 광고 개인 최적화 설정에 따라 달라질 수 있습니다.

## 4. 정보 저장과 삭제

사용자가 입력한 분석 기준, 관심 종목, 관찰 메모, 분석 실험 기록은 기본적으로 사용자의 기기 안에 저장됩니다. 관찰 메모와 분석 실험 기록은 앱에서 개별 삭제하거나 전체 삭제할 수 있으며, 앱 데이터 삭제 또는 앱 삭제로도 로컬 정보를 삭제할 수 있습니다.

광고 SDK 또는 외부 데이터 제공처가 처리하는 정보의 보관 기간과 삭제 방식은 각 제공처의 정책을 따릅니다.

## 5. 제3자 제공

앱 운영자는 사용자의 로컬 분석 기준, 관심 종목, 관찰 메모 또는 분석 실험 기록을 별도 서버에 업로드하거나 판매하지 않습니다. 다만 광고 제공과 시장 데이터 조회를 위해 Google AdMob 및 외부 데이터 제공처가 관련 정보를 처리할 수 있습니다.

## 6. 아동 개인정보

Strategy Workbench는 아동을 대상으로 설계된 앱이 아닙니다. 금융 및 투자 정보는 성인 사용자를 기본 대상으로 합니다.

## 7. 투자 관련 고지

Strategy Workbench에서 제공하는 정보는 투자 판단을 돕기 위한 참고 정보이며, 투자 자문, 매매 추천, 금융상품 권유가 아닙니다. 모든 투자 결정과 결과에 대한 책임은 사용자 본인에게 있습니다.

## 8. 정책 변경

이 개인정보처리방침은 앱 기능, 데이터 제공처, 광고 SDK, 관련 법령 또는 운영 정책 변경에 따라 업데이트될 수 있습니다. 중요한 변경이 있을 경우 앱 또는 스토어 등록정보를 통해 안내할 수 있습니다.
